# Hafiz Anwar Zia Advocate

> Trusted Legal Representation in Narowal & Zafarwal Chambers

Professional advocate and law chamber website for **Hafiz Anwar Zia Advocate** (Advocate High Court & District Courts). Features a dark luxury theme with gradient backgrounds, glassmorphism cards, Playfair Display typography, practice areas directory, chamber locator with interactive maps, client testimonials, legal FAQs, and consultation booking.

---

## Key Features

- **Practice Areas**: Civil Litigation, Criminal Defense, Family & Personal Matters, Court Representation, Revenue & Land Disputes, and Legal Drafting.
- **Dual Chamber Locations**:
  - **Narowal Chamber**: Chamber 40, District & Sessions Court Complex, Narowal
  - **Zafarwal Chambers**: Chambers 19 & 20, Court Building, Zafarwal
- **Fast Client Actions**: Instant consultation booking form, WhatsApp integration (+92 301 7672378), and direct phone dialing.
- **Design System**: Responsive glassmorphism + neumorphism cards, ambient lighting glows, Playfair Display headings, and Manrope typography.

## Zero-Config Vercel Deployment

This project is pre-configured for automatic 1-click import and deployment on Vercel:

1. Push this repository to your GitHub account:
   ```bash
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git push -u origin main
   ```
2. Open [Vercel Dashboard](https://vercel.com/new).
3. Click **Import** next to your GitHub repository.
4. Click **Deploy** — Vercel detects `.vercel/output` via `vercel.json` and publishes the live website automatically without requiring any manual configuration.
